## 使用规则

1. 写 README、简历或 GitHub 介绍时，优先引用“项目定位与架构”和“性能证据与复现”。
2. 面试前先读公开讲解提纲，再读 `D:\FindJob\面试私有资料\CppSearchServer\` 下的故事、题库和简历表述。
3. 遇到实现细节才进入 `归档`；归档保存学习过程、旧计划和原始实验，不是日常入口。
4. 新增文档先判断能否更新六份主文档；只有不可替代的原始数据或阶段过程才进入归档。
